# 백화점 거래 데이터로 고객 성별 예측 — 거래단위 Stacking

2026-1 머신러닝 수업 경진대회 **KML Challenge 2026S** · 팀 프로젝트 (4인: 권지원 · 이나경 · 이성진 · 이재하)

**성과: 거래단위 stacking 피처로 Public LB 0.72949 → 0.73330 (제출 당시 리더보드 1위), 피처 선별 후 0.73581**

## 문제

- 백화점 거래 내역(브랜드·코너·상품군·금액·할부·시간)으로 **고객 성별을 예측**하는 이진 분류, 평가지표 ROC-AUC
- 학습 고객 30,000명 / 평가 고객 19,995명, 고객 한 명이 여러 거래 행을 가짐
- 어려움: 고객의 약 50%가 남녀 상품을 섞어 사고(선물 구매), 약 70%가 여성 → 상품군만으로는 성별이 잘 갈리지 않음

## 접근

### 1. 기준 피처 확보 — 431 → 439개

교수님이 공유한 전년도 해커톤 1등 파이프라인을 우리 데이터 스키마에 맞게 옮겨 기준 피처 431개를 만들었습니다(구매 스타일·행동·달력·TF-IDF+SVD·타깃 인코딩 등). 여기에 가격대 구간·방문 주기·카테고리 금액 편향 8개를 더해 439개로 고정했습니다.

| 구성 | Public LB |
|---|---|
| 팀 기존 피처 211개 | 0.70925 |
| 대회 baseline | 0.71531 |
| 431 + AutoGluon | 0.72847 |
| 439 + AutoGluon | 0.72949 |

### 2. 고객 단위 피처의 포화 확인

439개 기준에서 피처 9종을 더 시도했지만(Word2Vec, 성별 순수도, 2-way 타깃 인코딩, KNN 협업필터링, pseudo-labeling 등) 어느 것도 OOF를 의미 있게 올리지 못했습니다. **제출 전에 5-fold OOF로 먼저 걸러서** 제출 횟수를 아꼈습니다.

> 해석: 모든 피처가 "고객 단위로 집계한 값"이라, 집계하는 순간 거래 하나하나의 정보가 사라진다.

### 3. 거래단위 Stacking — 돌파구 ★

집계 전 **거래 한 건 단위로 성별 확률을 먼저 예측**하고, 그 확률의 분포를 고객 단위로 다시 집계해 피처로 쓰는 2단계 구조를 설계했습니다.

```
거래 단위 데이터 → LightGBM 거래 모델 (거래 하나로 성별 예측, AUC 0.63)
               → 고객별로 확률 분포 집계 (평균·분위수·남성 비율·금액 가중 평균 …)
               → 축별 분리 (남성/여성/아동 상품, 고가/저가, 저녁, 주말에서 각각 얼마나 남성스러운가)
               → 고객 단위 피처 24개로 기존 439개에 추가
```

- **누수 차단**: 거래 모델의 OOF를 *고객* fold 기준으로 나눠, 같은 고객의 거래가 학습과 검증에 섞이지 않게 함
- 거래 하나로는 약한 신호(AUC 0.63)지만 고객 단위로 모으자 기존 피처가 못 잡던 정보가 살아남

| 버전 | 추가 내용 | OOF AUC (LightGBM) |
|---|---|---|
| 기준 439 | — | 0.71373 |
| v1 | 거래 확률 분포 집계 9개 | 0.71459 |
| v2 | + 남성 카테고리 거래 확률 gap | 0.71625 |
| **v3** | **+ 7개 축 분리 (24개)** | **0.71739** |
| v4 | + XGBoost 거래 모델·2-way 교차 (38개) | 0.71766 (수확체감 → v3 채택) |

**463(439 + v3) + AutoGluon → Public LB 0.73330.** LB 개선폭(+0.0038)이 OOF 개선폭(+0.0037)과 거의 같아 이 피처셋은 OOF를 믿을 수 있음을 확인했습니다.

### 4. 피처 선별과 안정성 점검

팀원 피처까지 합친 523개를 LightGBM 중요도로 정렬해 상위 250개만 남기자 **Public LB 0.73581**이 나왔습니다. 선별 결과에서도 거래단위 stacking 피처(`txp_mean`, `txp_median`, `txp_amtw` …)가 중요도 최상위를 차지했습니다. 이어서 시드 3개 × 5-fold로 fold별 점수 흔들림(표준편차 약 0.008)을 측정해 팀 최종 모델 선택의 근거로 공유했습니다.

## 핵심 교훈

1. **피처 > 모델** — 모델 교체·외부 블렌딩은 +0.0002, TF-IDF+SVD 피처는 +0.015
2. AutoGluon 위에서는 **기존 신호를 변형한 피처는 내부에서 흡수**되고, **새로운 종류의 정보**만 효과가 있음
3. 집계 단위를 바꾸는 것(거래 → 고객)이 피처 포화를 넘는 방법이었음
